# My agent: FitCoach AI

One-liner: A conversational fitness agent that helps users achieve their health & training goals with a personalized catalog of workout routines, exercises, and nutrition plans.

Tool coverage:
- Memory: User profile (fitness level, primary goals like strength or endurance, injuries, equipment available, dietary preferences)
- Tools: Routine lookup, exercise search, logging completed workouts, calculating fitness metrics (BMR, TDEE, macro split)
- Catalog/UI: Collection of workout plans and exercise routines rendered as A2UI cards/tables
- Image gen: Generating motivational workout milestone badges and posture/form visualization guides
- Sandbox: Python calculation of heart-rate training zones, macro distribution, and progressive overload math

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for macro/fitness math, Cloud Trace for latency monitoring
